NeoBIM
======

NeoBIM is an ambitious individual initiative to solve the fragmented use of software in the Architecture industry. It's not unheard of for widely known BIM tools to have exhorbitant subscription fees, and NeoBIM aims to focus on aiding independent architects to have better tooling that they can own.

Transparently, NeoBIM is a detached fork of Blender that comes with Bonsai (BIM tools) preinstalled. Adjustments based on feedback of a licensed architect are gradually being developed. 

There's this quote that we really like: "Plant flowers. If the bees come, wonderful. If they don't, you'll still have a beautiful garden."

So yeah, back to planting.
